选择主题预览的组织方式

三种方式都会保留主题、组件、排版和证据；区别在于后续作为项目原型约束时的可读性与自动化程度。

A · 组件目录
主题色板
已观测组件
推断组件
布局规则

组件目录优先

线性、易浏览；机器约束作为页尾 JSON。适合人工参考，但“组件—证据—布局”关联较分散。

B · 原型契约（推荐）
主题
排版
组件
证据
主题与密度
组件矩阵：观测 / 推断
页面布局样板
内嵌 contract JSON

契约优先

展示与 JSON 使用同一份证据清单；最适合作为后续原型构建的约束基线。

C · 页面样板优先
列表页样板
详情页样板
表单页样板

页面样板优先

最接近可见原型，但会把未在来源中证实的页面组合带入设计，边界较松。

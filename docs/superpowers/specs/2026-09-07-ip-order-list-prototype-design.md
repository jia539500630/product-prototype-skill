# IP 订单列表静态原型设计

## 目标

基于用户授权的 `/Users/li/byway/ip-order-frontend/dist` 构建产物，制作一个可直接在浏览器打开的订单列表工作台静态 HTML 原型。原型用于展示页面结构、基础组件、主题色与排版，不连接业务接口。

## 视觉契约

- 主操作与当前状态：`#079C66`；深绿强调文本：`#005226`。
- 表格表头：从 `#FAFEFD` 到 `#E5F9F6` 的纵向渐变；选中或悬停填充：`#E6F5F0`；当前行：`#EBFFF8`。
- 画布：`#F2F3F5`；内容面板：白色；主文本：`#303133`；次级文本：`#606266`；常规边框：`#DCDFE6`。
- 字体依次为 Helvetica Neue、PingFang SC、Microsoft YaHei、Arial 和无衬线后备字体。基准字号为 14px/24px；辅助信息为 12px；区域标题为 16px。
- 表单控件与按钮高度为 32px，紧凑控件为 24px；圆角 4px。弹窗样式仅在后续需要时使用 8px 圆角。

## 页面结构

1. 顶部工作栏显示系统名称、当前日期和用户入口。
2. 左侧导航显示订单相关模块，并明确当前的订单列表入口。
3. 主内容区包含面包屑、页面标题、主要操作按钮和简短说明。
4. 查询区提供订单号、患者姓名、开立科室、订单状态和日期范围等示例控件，以及查询与重置按钮。
5. 数据区展示订单号、患者、开立科室、医嘱类型、开立时间、状态和操作列；带有选中行、状态标签和悬停反馈。
6. 底部显示总数、页码与每页数量，呈现标准数据工作台闭环。

## 交互边界

- 所有按钮和控件保持视觉上可操作，但不请求网络、不保存数据。
- 查询与重置只作为静态原型控件呈现；不实现筛选逻辑。
- 原型不得复制源系统的标识、专有图标、真实患者信息或原始业务文案。

## 验收

- 在桌面端浏览器直接打开即可完整呈现，无外部资源依赖。
- 视觉上可识别原构建产物的绿色主题、紧凑密度、渐变表头和中文医疗业务工作台排版。
- 页面在 1280px 宽度下不产生横向布局错乱。
